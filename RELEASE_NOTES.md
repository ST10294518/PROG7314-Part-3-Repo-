# Winx — Final POE Release Notes (work in progress)

## Improvements added to this working copy
- Configurable Android API endpoint via Gradle property `WINX_API_BASE_URL`.
- Firebase Cloud Messaging receiving service and Android notification channel.
- Android notification and biometric manifest permissions.
- GitHub Actions for Android build/unit tests and ASP.NET API build.
- Expanded Git ignore rules for signing keys and build artifacts.

## Existing Part 2 features retained
- Firebase email/password authentication and Google Sign-In.
- Travel journal CRUD and media metadata API.
- Settings, biometric opt-in flow, and English/isiZulu in-app translations.

## Still required before claiming final completion
- Offline Room storage and automatic synchronisation integrated into CRUD screens.
- Cloud-hosted NoSQL database and actual binary blob uploads/downloads.
- Deployed authenticated API and push-message sender with device token management.
- Device-tested runtime notification permissions and end-to-end biometric login.
- Custom icon, production screenshots, signed release APK, test evidence, and GitHub final tag.
- User-supplied demonstration video link.
